# Industry Relevance

## SOC Analyst

The project demonstrates triage, indicator review, evidence-based scoring, and analyst-facing explanations.

## Email Security Analyst

The project models sender, URL, attachment and social-engineering signals commonly considered in email security workflows.

## Cybersecurity Analyst

The project demonstrates defensive analysis, secure coding, logging/storage design and risk-based classification.

## Threat Intelligence Analyst

The URL and sender modules establish a foundation for later enrichment with reputation, WHOIS/DNS, threat-intelligence feeds and domain intelligence.

## Incident Response Analyst

The analysis history and recommendations can support initial triage before escalation.

## Security Awareness Team

The awareness module converts detection logic into user-facing phishing education.

The prototype is intentionally static and safe; it does not replace enterprise secure email gateways, sandboxing or live reputation systems.
